## External integration

XKeen, Xray-core, Entware and optional transport components such as Nginx are
installed separately. Their source code is not included in the XKeen Stats
binary. See README.md for upstream project links. GitHub Actions and GitHub CLI
are release-build tools, not router runtime dependencies.
