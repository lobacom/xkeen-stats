# Встроенные шаблоны обхода Xray

Каталог `bypass_templates.json` содержит четыре снимка проверенных IPv4-диапазонов.
Дата каждого снимка указана в каталоге и в редакторе. Шаблоны доступны сразу после
установки панели, без загрузки адресов из сети.

| Шаблон | Параметры нового правила |
| --- | --- |
| Кинопоиск / CDN Яндекса | Все протоколы, весь LAN |
| Яндекс Телемост | Все протоколы, весь LAN |
| VK: звонки и мессенджер | Все протоколы, весь LAN |
| Steam SDR: игровые соединения | UDP 27015–27140, выбранные устройства |

Для Кинопоиска выбраны две подсети из [диапазонов Яндекса](https://yandex.ru/ips).
Обе использовались при проверке воспроизведения. В них могут находиться и другие
сервисы Яндекса.

Телемост: веб-интерфейс, API, медиасерверы, TURN/STUN из раздела «Телемост»
[сетевых требований Яндекс 360](https://yandex.ru/support/yandex-360/business/admin/ru/network-settings).
Некоторые адреса перекрываются подсетями Кинопоиска. Они оставлены в шаблоне
Телемоста, чтобы он работал независимо от отдельного правила CDN.

VK: сети веб-интерфейса и медиасерверов, проверенные при звонках через браузер
и приложение; владельцы диапазонов сверялись по RIPE. Это проверенный набор,
а не официальный исчерпывающий список всех серверов VK.

Steam SDR: точные IPv4-адреса ретрансляторов из
[опубликованного Valve SDR-конфига Deadlock](https://api.steampowered.com/ISteamApps/GetSDRConfig/v1/?appid=1422450).
Другие игры с этими SDR-узлами и портами тоже могут совпасть с правилом.
Обход всех игр Steam этим списком не гарантируется.

IPv6 в каталог не включён: ранее проверялись именно эти наборы IPv4.
В редакторе выбор шаблона заполняет поля без применения firewall. Пользователь
может исправить список и область устройств, затем сохранить правило обычным способом.
При редактировании существующего правила шаблон сохраняет область устройств и
включённость, чтобы не расширить исключение или не включить его неожиданно.

## Обновление каталога

Из корня репозитория запустите команду с Python 3.8 или новее. Она скачает текущие списки
Valve и Яндекса и покажет, какие IPv4-адреса и подсети появились или исчезли.

```sh
python tools/refresh_bypass_templates.py
```

После проверки изменений повторите команду с `--write`. Она заново покажет разницу,
запишет её в `bypass_templates.json` и обновит дату изменившихся шаблонов. Для
повторяемой сверки можно передать `--source-dir ПАПКА` с сохранёнными `valve.json`
и `telemost.html`.

Для Steam берутся IPv4-адреса из `pops.*.relays`. Если Valve указала порты за
пределами текущего диапазона шаблона, команда остановится для ручной проверки.
Для Телемоста берутся IPv4 из таблицы видеосвязи до строки `messenger.360.yandex.ru`,
с которой начинаются общие зависимости чата. Подсети Кинопоиска и VK сверяются
по фактическим подключениям. Общие диапазоны владельцев помогают сверить адреса.

При сборке обновлённый каталог попадёт в новый релиз. Чтобы перенести новый список
в действующее правило, выберите шаблон в редакторе и сохраните правило.
